# CRTSHT press assets

The public press page is /press and is rendered by /press.php.

Upload downloadable press files directly into this folder. PDF, TXT and ZIP files are listed automatically.

Recommended filenames:
- CRTSHT_Handout_2026.pdf
- CRTSHT_Press_Release_DE.pdf (optional; the TXT version is already here)
- CRTSHT_Press_Release_EN.pdf (optional; the TXT version is already here)
- CRTSHT_Press_Kit_2026.zip (optional)

Upload high-resolution press images into:
- /press/images/

Recommended image filenames:
- CRTSHT_01_Marco_Spitzbarth_Wall.jpg
- CRTSHT_02_Installation_Wall.jpg
- CRTSHT_03_Genuine_Print.jpg
- CRTSHT_04_Back_Wallet_Seedwords.jpg
- CRTSHT_05_Mooncake_Box.jpg

JPG, JPEG, PNG and WEBP files in /press/images/ are shown automatically on the press page and link to the original high-resolution file.

If a dedicated press email is desired, set CRTSHT_PRESS_EMAIL in private/config.php. The page falls back to CRTSHT_LEGAL_EMAIL.
